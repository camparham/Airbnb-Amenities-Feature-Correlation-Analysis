## Overview
Analyzed Airbnb listings to uncover how features like number of beds, bathrooms, and amenities interact using correlation heatmaps. The project focused on identifying feature relationships that drive booking trends and providing actionable recommendations for hosts, investors, and property managers.

## Key Insights
* Core layout features (guests, bedrooms, beds) scale predictably together.
* Amenities such as Wi-Fi, kitchen, and workspace operate independently of property size — offering hosts flexible levers for competitiveness.
* Larger listings (4+ guests) dominate bookings, signaling strong demand for group/family accommodations.
* Location-based amenities (e.g., garden view, parking) do not scale predictably with layout.

## Next Steps
* Regression to model pricing and booking frequency.
* Clustering to reveal market segments.
* Time-series to track amenity adoption trends.
* Sentiment analysis to link features with review outcomes.

## Real-World Implications
* Hosts can maximize bookings by adding high-value amenities regardless of property size.
* Multi-room properties may yield higher ROI due to group demand.
* Property managers can prioritize upgrades aligned with guest booking behaviors.

* **Statistical Reasoning:** Applied correlation analysis and proposed regression/clustering extensions.
* **Business Insights & Strategy:** Translated raw data into actionable recommendations for hosts and investors.
* **Storytelling with Data:** Structured findings into clear insights and next steps that connect technical outputs to real-world outcomes.
